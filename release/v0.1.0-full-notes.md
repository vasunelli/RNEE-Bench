# RNEE-Bench full frozen artifacts v0.1.0

This release supplies the complete frozen data, model, prediction, and public test-fixture payload for the lightweight `vasunelli/RNEE-Bench` repository.

Download **all three** split 7-Zip volumes and keep them in the same directory:

- `RNEE-Bench-full-artifacts-v0.1.0.7z.001` — 1,992,294,400 bytes
- `RNEE-Bench-full-artifacts-v0.1.0.7z.002` — 1,992,294,400 bytes
- `RNEE-Bench-full-artifacts-v0.1.0.7z.003` — 1,118,597,247 bytes

Also download `RNEE-Bench-full-artifacts-v0.1.0-SHA256SUMS.txt`. Verify the volumes before extraction, then extract only `.7z.001` at the root of a cloned repository. The other volumes are consumed automatically.

```bash
sha256sum -c RNEE-Bench-full-artifacts-v0.1.0-SHA256SUMS.txt
git clone https://github.com/vasunelli/RNEE-Bench.git
cd RNEE-Bench
7z x /path/to/RNEE-Bench-full-artifacts-v0.1.0.7z.001
python scripts/verify_full_release.py
```

The payload contains:

- complete TRAJECTORY_BUILD map-matched points, matched edges, and row-level enriched trajectory partitions;
- SEGMENT_SPLIT complete, QA-valid, and prediction-usable segments plus leakage-controlled split assignments;
- THEORY_VALIDATION paired, ensemble, and negative-control prediction Parquet files;
- current RPM-only prediction and inference artifacts;
- 192 frozen THEORY_VALIDATION Joblib model objects and sidecars;
- the public contract fixtures required to run the checked-in test suites.

The repository contains the construction, training, inference, and verification pipeline; schemas and inventories; dataset and model cards; and licensing/attribution notices. Current RPM-only model binaries were not serialized by the frozen run and are therefore not included or refitted for this release. Joblib files are executable Python serialization artifacts: verify checksums and load them only from a trusted release.

Public paths and labels use semantic stage names for clarity and portability. The accompanying repository and volume payload were checked for private machine paths, technical experiment identifiers, and internal review labels.
