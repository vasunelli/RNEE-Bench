# Manuscript tables

`table1.csv` through `table4.csv` contain the four manuscript tables. The two `table*_values.csv` files map displayed numerical values to their full-precision sources; referenced source paths are populated by the data-download command.

Complete primary prediction results are in [results/primary_effects.csv](../results/primary_effects.csv). Accounting quantities are in [results/accounting_table.csv](../results/accounting_table.csv). The primary fixed-HGB results and estimator-selection sensitivity remain separate.
