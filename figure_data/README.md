# Figure source data

The compact files here contain Figure 3 gain/attenuation values and Figure 5 predictive-overlap values. Additional data are installed by `python scripts/download_data.py`:

| Figure | Source |
|---|---|
| 1 | VED/OSM construction resources linked in [sources.md](../docs/sources.md) |
| 2 | Method schematic in [figures/figure_02.svg](../figures/figure_02.svg) and [protocol.md](../docs/protocol.md) |
| 3 | `figure03.csv` and `results/primary_effects.csv` |
| 4 | `results/correspondence_controls.csv` and `results/correspondence_control_draws.csv` |
| 5 | `figure05.csv` and `results/predictive_overlap.csv` |
| 6 | `results/model_sensitivity.csv` |
| 7 | `results/rpm_diagnostic.csv` and `results/road_attribute_overlap.csv` |
| 8 | `data/energy/data/diagnostics/spatial/` |
| 9 | `data/energy/data/diagnostics/target_decile/` |
| 10 | `data/energy/data/diagnostics/speed/` |
| 11 | `data/energy/figure_data/figure11.csv` and `data/energy/figure_data/figure11/` |

Paths in this table are relative to the repository root unless the file is in this directory. Scientific source files retain their stored record keys. Figure artwork is supplied separately in [figures/](../figures/README.md).
